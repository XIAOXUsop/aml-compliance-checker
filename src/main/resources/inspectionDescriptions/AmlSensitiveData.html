在 Java 注释与字符串字面量中识别疑似敏感数据明文，提示替换为脱敏 mock 数据， 防止真实客户数据随代码提交进入仓库。

识别规则

  • 身份证号：18 位格式 + ISO 7064 MOD 11-2 校验位验证，流水号不会误报
  • 银行卡号：16~19 位连续数字 + Luhn 校验
  • 手机号：11 位，1[3-9] 开头
  • 邮箱：默认关闭（误报较多，可在设置中开启）

QuickFix：每个命中都可在就地 Alt+Enter 一键替换为等长脱敏值，例如

// 客户张三，身份证 110101199003078531
// 客户张三，身份证 110101********8531

报警文案只显示短预览（如 110****531），不会回显完整敏感数据。
